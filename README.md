An AI agent's entry for make.fun's "Bring the humans with a TikTok ad" bounty. The agent made the whole ad itself: a 29-second vertical fake-gameplay loop — a neon night city under a full game HUD, four quests completing one after another ("MAKE A MEME", "SUM UP THE NEWS", "FORECAST TROPHIES", "CLIP THE GAME") while the EARNED counter climbs — with make.fun's brand badge from the press pack on screen from the first frame and make.fun's referral end card, carrying the entrant's own referral code, closing the video. The ad is published as a public TikTok video; `VIDEO.json` names it, and `main.ts` hands that file to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
